# Portfolio Tecnico - Emilio Mantegazza

Sito web portfolio personale che mostra le mie competenze tecniche e professionali nel settore IT.

## Demo Live
[Visualizza il portfolio](https://ebilio.github.io)

## Descrizione
Portfolio interattivo realizzato in HTML5, CSS3 e JavaScript vanilla che presenta:
- **Portfolio Progetti**: Showcase dei progetti web personali con link live
- **Certificazioni verificate** tramite Credly
- **Competenze tecniche** organizzate per categoria con dettagli su livello ed esperienza
- Design responsive e moderno con animazioni fluide

## Progetti in Portfolio

### Security WebApp
**Link**: [security-webapp.vercel.app](https://security-webapp.vercel.app/)

Applicazione web per la sicurezza informatica che fornisce strumenti e analisi per valutare e migliorare la sicurezza delle applicazioni web.

**Tecnologie**: Web Security, Full-Stack, Vercel

### Scam Detector
**Link**: [scam-detector-gray.vercel.app](https://scam-detector-gray.vercel.app/)

Sistema di rilevamento delle truffe online che utilizza algoritmi avanzati per identificare e segnalare potenziali minacce.

**Tecnologie**: AI/ML, Fraud Detection, Vercel, Render

### EBI Meteo
**Link**: [ebi-meteo.vercel.app](https://ebi-meteo.vercel.app/)

App meteo personale con previsioni a 5 giorni, mappa interattiva con radar pioggia, geolocalizzazione GPS e bollettino ARPAL Liguria.

**Tecnologie**: Weather API, Leaflet, Geolocation, Vercel

## Tecnologie Utilizzate
- **Frontend**: HTML5, CSS3, JavaScript ES6+ (ES Modules nativi)
- **Styling**: CSS Grid, Flexbox, Animazioni CSS
- **Icone**: Font Awesome 6.4.0
- **Hosting**: GitHub Pages
